clean link maker

Clim

ショートカットや右クリックから、テンプレートで整形したページ情報をすばやくコピーできます。

URLコピー

初期テンプレートは {{url}}。現在のページURLを加工せずそのままコピーします。

ショートカット

スロット1はAlt + Shift + C、MacではControl + Shift + C。スロット2〜4はChrome側で割り当てできます。

ページ右クリック

Webページ上の右クリックメニューからClimでURLをコピーできます。

テンプレート

{{title}} や {{cleanTitle}}、if条件、文字連結でコピー形式を作れます。

template guide

テンプレートの書き方

テンプレート画面でコピー形式を作り、差し込み画面で独自の項目を追加できます。

[{{title}}]({{url}}) [{{cleanTitle}}]({{url}}) {{title + " - " + url}} {{if selectedText then "> " + selectedText + "\n\n" else ""}}[{{title}}]({{url}})
