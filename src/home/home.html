clim

日本語Webページを、クリーンなMarkdown/Scrapbox/HTMLリンクとしてコピーします。

使い方

ショートカット

Markdownリンクは初期設定でコピーできます。

Windows/Linux
Alt + Shift + C
Mac
Control + Shift + C

右クリック

ページ上で右クリックし、climでクリーンコピーから形式を選べます。

カスタマイズ

サイト名の除去やドメインごとのトリミングルールは設定ページで変更できます。

対応フォーマット

  • [タイトル](URL)
  • [タイトル URL]
  • タイトル URL
  • <a href="URL">タイトル</a>
  • frontmatter + Markdown
  • 選択テキスト引用 + Markdown
