# Chromeウェブストア掲載文

## 説明

Clim は、現在開いているWebページのURLやタイトル、メタ情報をショートカットや右クリックから素早くコピーするためのChrome拡張機能です。

4つのショートカットスロットを用意しており、Chrome標準のショートカット設定から自由にキーを割り当てできます。コピー内容はテンプレートでカスタマイズでき、URLコピー、Markdownリンク、引用つきメモ、HTMLリンク、Scrapboxリンク、Notionメモなど、普段使っているノートアプリやドキュメントに合わせた形式を作成できます。

テンプレートでは `{{url}}` や `{{title}}` などのページ情報を差し込めます。文字列、連結、条件分岐にも対応しているため、選択テキストがある時だけ引用を付ける、といった出力も作れます。ルールと変数画面から変換ルールや独自変数を追加し、サイトに合わせたタイトル整形やURL由来の値もテンプレートで利用できます。

コピー処理はページ上で完結し、外部サーバーへの送信やリモートコードの実行は行いません。頻繁に使う人向けに、コピー完了トーストのON/OFFも設定できます。

## 短い説明

ショートカットや右クリックから、テンプレートで整形したページ情報をすばやくコピーします。

## カテゴリ

仕事効率化

## 単一用途

Clim の単一用途は、現在開いているWebページの情報をユーザーが設定したテンプレート形式でクリップボードへコピーすることです。
